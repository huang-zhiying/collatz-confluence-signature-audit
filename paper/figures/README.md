# Figures

The manuscript's figures are the English set generated by `make_figures_en.py`
(five PNGs, about 5 s, matplotlib only, no input files):

| script | output | note |
|---|---|---|
| `make_figures_en.py` | `fig0_trajectory27.png`, `fig1_z_distribution.png`, `fig2_attack_cost.png`, `fig3_d_entropy.png`, `fig4_entropy_vs_k.png` | the set used in the paper |
| `make_trajectory27.py` | `fig0_trajectory27.png` | earlier single-figure script (Chinese labels); the appendix still names it |
| `make_figures.py` | `fig1`--`fig3` | earlier Chinese set, kept for history |

Run `python make_figures_en.py` in this directory to regenerate. The numbers in
the figures come from the fixed seeds inside the script, so the plots are
deterministic; the committed PNGs are the exact files used in the manuscript
(PNG bytes can differ across matplotlib versions without changing the plot).
